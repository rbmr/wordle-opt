# Benchmark History

Generated by `cargo run --release -- benchmark [-n N]` (see `src/main.rs::run_benchmark`).
Entries are appended automatically; do not hand-edit past runs.

**Format guarantees, so this file can actually be trusted for comparisons:**
- Each size uses a *fixed, deterministic* candidate subset: the first N dictionary
  entries, sorted (`(0..N).collect()`), identical to the convention used by the
  golden regression tests in `src/solver.rs`. Nothing here is randomly sampled.
- Every run header records the git commit hash, hostname, and CPU count it ran
  on. A cost/state count is only comparable to another entry at the same N; a
  wall-clock time is only meaningfully comparable to another entry on the same
  host.
- For sizes below 750, each size is solved 3 times and reports min/avg/max wall
  time; the solve itself asserts cost is identical across those repeats (same
  input + same code must give the same answer), so any variance shown is
  scheduling/timing jitter only, never a different result.
- Prior exploratory benchmarking (randomly sampled candidates, no commit
  stamping, narrative claims not tied to a specific run) has been moved to
  `benchmark_history_legacy.md` and should not be used for comparisons.
